## 🎯 Особенности UI/UX

### 1. Интерактивность
- **Draggable**: Можно перетаскивать за заголовок
- **Scrollable**: Вертикальная прокрутка для длинного меню
- **Toggle hotkey**: Right Control для показа/скрытия

### 2. Адаптивность
- Автоматическое изменение размера canvas при добавлении элементов
- Правильное позиционирование относительно центра экрана
- Responsive padding и margins

### 3. Визуальная обратная связь
- Изменение цвета при наведении (через AutoButtonColor)
- Анимация при нажатии
- Визуальное различие между состояниями ON/OFF
- Цветовое кодирование статуса

### 4. Доступность
- Контрастные цвета для хорошей читаемости
- Достаточно большие кнопки (42-45px высота)
- Четкие названия функций
- Логическая группировка по секциям

## 🔧 Технические детали

### ZIndex слои
```
Слой 1: MainFrame
Слой 2: Title, ScrollFrame, StatusBar
Слой 3: TitleText, SubTitle, CloseButton, элементы меню
Слой 4: TextButton внутри элементов
```

### DisplayOrder
```
DisplayOrder: 999999 (самый верхний уровень)
```

### Защита GUI
```lua
-- Попытка защиты от обнаружения
pcall(function()
    if syn and syn.protect_gui then
        syn.protect_gui(ScreenGui)
    end
end)

-- Резервное размещение
if not PlayerGui then
    ScreenGui.Parent = CoreGui
end
```

## 📱 Пример использования

### Открытие GUI
1. Нажмите **Right Control**
2. Окно появится в центре экрана

### Навигация
1. Используйте **скроллинг** для просмотра всех функций
2. Кликните на **toggle** для включения/выключения
3. Кликните на **кнопку действия** для выполнения команды

### Закрытие GUI
1. Нажмите **X** в правом верхнем углу (скрыть)
2. Нажмите **Right Control** (показать снова)
3. Используйте **Destroy GUI** для полного удаления
