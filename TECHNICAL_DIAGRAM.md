├─ Создание: При активации NoClip
├─ Работа: Перед каждым физическим расчётом
└─ Удаление: При деактивации NoClip

├─ Работа: 0.1 секунды
└─ Удаление: Автоматически после TP

├─ Создание: При телепортации на базу
├─ Работа: 0.15 секунды
└─ Удаление: Автоматически после TP

BodyPosition "GnomHub_AutoStealTP"

## 🎯 Приоритет выполнения RunService

```
ПОРЯДОК ВЫПОЛНЕНИЯ В ОДНОМ КАДРЕ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. PreSimulation        ← Предотвращение отката (NoClip)
   ↓
2. Физические расчёты   ← Рoblox Engine
   ↓
3. Heartbeat            ← Отключение коллизий (NoClip)
   ↓
4. RenderStepped        ← Extreme NoClip (если активен)
   ↓
5. Рендеринг кадра      ← Roblox Engine


ПРЕИМУЩЕСТВА ТАКОГО ПОРЯДКА:
━━━━━━━━━━━━━━━━━━━━━━━━━━

✓ PreSimulation видит попытки отката ДО их применения
✓ Heartbeat корректирует после физики, но до рендеринга
✓ RenderStepped гарантирует финальное состояние перед показом
✓ Минимальные конфликты между системами
```
