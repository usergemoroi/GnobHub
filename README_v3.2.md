## 🎯 Основные возможности

### 🏃 Движение
- **Fly** - полёт с управлением WASD + Space/Shift
- **NoClip** - проход сквозь стены БЕЗ телепортации назад
- **Extreme NoClip** - 30 секунд гарантированного прохода через любые стены
- **Speed Boost** - ускорение ходьбы
- **Infinite Jump** - бесконечный прыжок
- **Teleport Forward** - телепортация на 25 стадов вперёд
- **Teleport to Base** - умная телепортация на вашу базу

- **ESP** - подсветка игроков и предметов
- **Highlights** - цветная обводка объектов
- **Дистанция** - показывает расстояние до объектов

### 🤖 Автоматизация
- **Auto-Farm Coins** - автоматический сбор монет

### 🛡️ Защита
- **Anti-Kick** - защита от кика (включена по умолчанию)

- **Anti-Ragdoll** - защита от падения

## 🔧 Решение проблем

### ❌ NoClip телепортирует назад

**Решение 1:** Используйте стандартный NoClip
```
1. Выключите старый NoClip
2. Включите новый NoClip
3. Теперь работает без отката!
```

**Решение 2:** Используйте Extreme NoClip
```
1. Нажмите кнопку "Extreme NoClip (30s)"
2. 30 секунд гарантированного прохода
```

### ❌ Телепортация вперёд не работает

**Решение:**
```
1. Нажмите "Teleport Forward (25 studs)"
2. Новая система использует плавную телепортацию
3. Античит не блокирует перемещение
```

### ❌ "Base not found"

**Решение:**
```
1. Новая система ищет базу по 10+ вариантам названий
2. Если не найдена - используйте Auto-Steal
3. Или телепортируйтесь вручную
```

## 📊 Технические детали

### Использованные технологии

| Компонент | Технология | Цель |
|-----------|------------|------|
| NoClip | RunService.Heartbeat | Отключение коллизий |
| NoClip | RunService.PreSimulation | Предотвращение отката |
| Extreme NoClip | RunService.RenderStepped | Максимальная частота |
| Телепортация | BodyVelocity + CFrame | Плавное перемещение |
| Поиск базы | Рекурсивный GetDescendants | Умный поиск |

### Архитектура

```
NoClip v3.2

Extreme NoClip

Телепортация
```
