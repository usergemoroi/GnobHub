# 🧠 GNOM HUB v3.1 - Roblox Script для "Steal a Brainrot"

## 📋 Описание
GNOM HUB v3.1 - это полнофункциональный скрипт для игры Roblox "Steal a Brainrot" с полностью рабочим GUI интерфейсом и системой защиты.

## 🎮 Функции

### 🚀 Движение
- **Teleport Forward** - телепорт вперед на 25 studs
- **Teleport to Base** - телепорт на свою базу
- **Fly** - полет с управлением через WASD + Space (вверх) / Shift (вниз)
- **NoClip** - прохождение сквозь стены
- **Walk Speed Boost** - ускорение ходьбы
- **Infinite Jump** - бесконечный прыжок

### 👁️ Визуализация
- **ESP** - подсветка игроков и Brainrot объектов
  - Отображение расстояния
  - Показ здоровья игроков
  - Highlight эффект

### ⚙️ Автоматизация
- **Auto-Farm Coins** - автоматический сбор монет
- **Auto-Steal Brainrot** - автоматическая кража Brainrot и возврат на базу

### 🛡️ Защита
- **Anti-AFK** - защита от кика за неактивность
- **Anti-Kick** - защита от кика через RemoteEvents
- **God Mode** - бесконечное здоровье
- **Anti-Ragdoll** - предотвращение падений и оглушений

### 🔧 Утилиты
- **Destroy GUI** - полное удаление скрипта и очистка

## ⌨️ Управление
- **Right Control** - открыть/закрыть GUI
- **X (в GUI)** - скрыть/показать окно
- **WASD** - движение в режиме полета
- **Space** - подъем в режиме полета
- **Shift** - спуск в режиме полета

## 🐛 Известные проблемы и решения

### Проблема: Текст не отображается в GUI
**Решение**: Эта проблема была полностью исправлена в v3.1. Убедитесь, что вы используете последнюю версию.

### Проблема: Fly не работает
**Решение**: Убедитесь, что ваш персонаж полностью загружен. Попробуйте отключить и включить функцию снова.

### Проблема: NoClip телепортирует персонажа
**Решение**: Исправлено в v3.1. Теперь NoClip корректно отключает коллизии без телепортации.

### Проблема: Auto-Steal не находит Brainrot
**Решение**: Убедитесь, что объекты называются "brainrot" (регистр не важен). Скрипт ищет в радиусе 300 studs.

## 🔧 Настройки (в коде)

Вы можете изменить следующие параметры в начале скрипта:

```lua
Settings = {
    FlySpeed = 50,          -- Скорость полета
    WalkSpeed = 50,         -- Скорость ходьбы
    JumpPower = 75,         -- Сила прыжка
    TeleportDistance = 25,  -- Дистанция телепорта
    ESP_RefreshRate = 1,    -- Частота обновления ESP (секунды)
}
```
